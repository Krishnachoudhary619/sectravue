# SpectraVue

Next.js shop for SpectraVue interactive panels and digital signage.

- Browse products, add to cart, or buy now
- No login and no payment
- Place order / Buy now opens WhatsApp (`+91 9321618509`)
- Prices shown as **Price on request**

```bash
npm install
npm run dev
```

The previous static site is archived in `legacy/`.
